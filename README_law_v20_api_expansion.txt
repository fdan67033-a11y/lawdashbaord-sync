변경 요약
1) 검색대상 8종 추가 (모두 JSON 실측 검증 완료)
   - 행안부 1차해석(moisCgmExpc): 지방세 유권해석. 법제처 법령해석례(expc)와 별도 자료
   - 조세심판원 결정례(ttSpecialDecc): 지방세 불복 심판결정례
   - 행정심판례(권익위)(decc)
   - 헌재결정례(detc)
   - 감사원 사전컨설팅(baiPvcs)
   - 별표서식(법령/행정규칙/자치법규)(licbyl/admbyl/ordinbyl):
     검색 결과를 법령창에 열면 PDF 미리보기·HWP 다운로드 버튼이 표시됩니다.

2) 기장군 자치법규를 법제처 API 직접조회로 전환
   - target=ordin&org=6260000&sborg=3400000 (실측 검증, 현행 532건)
   - 검색어를 비우면 기장군 전체 목록을 불러오는 기존 동작 유지
   - API 장애 시에만 기존 수동 목록(gijang_ordinances_manual.json)으로 자동 대체
   - 이제 항목에 실제 자치법규 ID/MST가 있어 본문(조문) 표시가 안정적입니다

3) 법령창 도구 버튼 (현행법령을 열었을 때 상단에 표시)
   - [위임법령]: 조문별 위임 시행령·시행규칙·자치법규 현황 (새 탭, 자체 표)
   - [신구법]: 신구조문 대비표 (법제처 새 탭)
   - [3단비교]: 법률-시행령-시행규칙 비교 (법제처 새 탭)
   - 사례형/별표서식 항목에는 [원문 새 탭] 버튼 표시

4) 검색 파라미터 확장
   - 시행일 범위(efYd) 검색이 자치법규(전체/기장군)에도 적용됩니다
   - 검색대상 프리셋에 [심판·해석], [서식] 버튼 추가

5) 사례형 본문 정규화 개선
   - 법령해석례·행정심판례 등의 본문이 질의요지/회답/이유/재결요지 등
     섹션 카드로 표시됩니다 (기존: JSON 원문 덤프)
   - 헌재 전문의 [주 문]/[이 유] 표지 분리 지원

6) 판례 본문 처리 개선 (v20 추가 패치, 2026-06-12 저녁)
   - 국세법령정보시스템(국세청) 출처 판례: 법제처 API가 본문을 주지 않는 자료는
     국세청 시스템에서 전문을 직접 받아 와 요지/재판경과/주문/이유/관련문서를
     한 스크롤 섹션 카드로 표시합니다 (복사·노트연결·하이라이트·글자크기 모두 동작)
   - 받아오기에 실패하면 기존 원문 뷰어 iframe으로 자동 대체
   - 우선순위: 법제처 텍스트 본문 > JSON 섹션 > 국세청 전문 텍스트 > 원문 뷰어 iframe
   - 고친 버그: iframe 추출 정규식(src = 공백 미대응), '주문 항목 없음' 안내가
     본문 판정을 오염시켜 오류 응답이 본문으로 표시되던 문제 (둘 다 v19부터 존재)

7) 조문 인용 링크 (법제처 화면처럼 조문 간 이동) — v20 추가
   - 현행법령과 조례(자치법규) 본문을 열면 조문 안의 「법령명」·제○조 인용이
     파란 점선 링크가 됩니다 (조례는 법제처 연결 데이터에 법령ID가 직접 들어 있어
     "같은 법 시행령"·"제32조" 같은 인용도 정확히 연결됩니다)
   - 법령명이 생략된 "제8조" 같은 인용도 법제처가 미리 계산한 연결 정보를 그대로
     써서 정확히 대상(예: 지방세기본법 제8조)으로 연결됩니다
   - "같은 법"·"이 법" 같은 상대참조도 실제 대상 법령으로 연결됩니다
   - 클릭하면 대상 법령을 열고 해당 조문으로 자동 스크롤 + 노란 하이라이트
   - 검색 패널의 "인용 링크: [옆 창][팝업]" 토글로 여는 방식을 고를 수 있습니다
     (옆 창=2/3번 법령창에 나란히, 팝업=법제처 원문 새 창). 설정은 저장됩니다
   - 기존 카드 기능(복사·노트연결·하이라이트·글자크기·조문점프) 전부 그대로 유지
   - 부수효과: 조례 본문이 이제 조문별로 제대로 나뉘어 표시됩니다(이전엔 한 덩어리)
   - 판례에는 링크를 붙이지 않습니다 (약칭·구법 인용이 많아 자동 연결이 틀릴
     위험이 커서 의도적으로 제외 — 판례 인용은 직접 확인 권장)
   - 출처: 법제처 본문 뷰어(법령 lsInfoR.do / 조례 ordinInfoR.do)의 연결 데이터,
     OC 인증 없이 동작

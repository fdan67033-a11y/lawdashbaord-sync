[0] 사전 준비 (한 번만)
  - Windows + Python 3.12 설치 (설치 시 "py 런처" 포함 기본값 유지)
  - 이 폴더에서 명령창 열고:  py -m pip install -r requirements.txt
    (Flask, requests 등 설치 — 인터넷 필요. 학습 대시보드만 쓸 거면 생략 가능)

----------------------------------------------------------------
[1] 법제처 대시보드 (조문·판례·질의상담)   ※ Python 필요
----------------------------------------------------------------
  - "법제처대시보드_시작.bat" 더블클릭
  - 자동으로 http://localhost:6155 열림
  - 조문 검색 → 우측 [노트][판례][질의·상담] 탭
  - 종료: 검은 명령창 닫기

----------------------------------------------------------------
[2] 기출 학습 대시보드 (객관식 7,195문제, 현행화+해설)  ※ Python의 http.server만 사용
----------------------------------------------------------------
  - "학습대시보드_시작.bat" 더블클릭
  - 자동으로 http://localhost:6160 열림
  - 문제풀이 / 오답노트 / 통계 탭, 시험·과목·연도 필터
  - 선택지 클릭 → 정답·내 해설·현행 배지(현행/개정/검증필요)
  - 진도(정오답·오답노트)는 그 브라우저에 저장됩니다(localStorage).
    ※ 다른 브라우저/PC면 진도는 따로 시작됩니다.
